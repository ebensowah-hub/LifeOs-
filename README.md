# LifeOS
Mobile-first, offline-capable PWA prototype for the user's personal progress system.

Includes: IT/Courseware, cybersecurity, web development, project management, studies, photography, video editing, fitness, income, first $500 goal, device status, daily tasks, and a basic offline AI Coach.

Open `index.html` in a browser or deploy the folder to any static web host. For full offline PWA installation on iPhone, it must be served over HTTPS (localhost also works for development).
